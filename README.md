# trip

放旅行行程與筆記的 repo。依出發年月用資料夾整理，例如 `202607`。

每個行程通常會有：

- Markdown：方便編輯與版本紀錄
- HTML：方便用瀏覽器觀看

## 線上觀看（GitHub Pages）

若要直接用網址開 HTML，需先開啟 GitHub Pages：

1. 打開：https://github.com/devil20571/trip/settings/pages
2. **Source** 選 **Deploy from a branch**
3. **Branch** 選 `main`，資料夾選 `/ (root)`
4. 按 **Save**

等 1～2 分鐘後，即可用：

`https://devil20571.github.io/trip/<年月>/<檔名>.html`

開啟對應行程網頁。

若出現 `There isn't a GitHub Pages site here.`，代表 Pages 尚未啟用或還在部署中。
